# Smart-Timetable-Scheduler
Smart Timetable Scheduler is a web-based PHP and MySQL application that automates timetable management for educational institutions. It allows admins to manage faculty, students, subjects, departments, holidays, and lecture schedules, generate timetables, prevent holiday conflicts, and view data through a responsive dashboard and calendar interface.
📖 Project Description Smart Timetable Scheduler is a web-based application developed to automate and simplify timetable management for educational institutions. The system allows administrators to manage faculty, students, subjects, departments, holidays, and lecture schedules. It also provides an interactive dashboard, calendar-based holiday management, and automatic timetable generation with holiday conflict prevention.
# 🛠️ Tech Stack - 🌐 HTML5 - 🎨 CSS3 - ⚡ JavaScript - 🐘 PHP - 🗄️ MySQL - 💻 XAMPP

# ✨ Main Features - 🔐 Admin Dashboard - 👨‍🏫 Add / View / Edit / Delete Faculty - 🎓 Add / View / Edit / Delete Students - 📚 Add / View / Edit / Delete Subjects - 🏢 Department-wise Faculty & Subject Management - 🗓️ Generate Timetable - 📖 View Timetable - 📅 Holiday Calendar (2026-2030) - 🔴 Public holidays highlighted in red - 🟢 Current date highlighted - 🚫 Prevent timetable generation on holidays - 📱 Responsive and user-friendly interface
